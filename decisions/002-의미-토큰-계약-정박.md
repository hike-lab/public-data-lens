# 002 — 의미 토큰 층을 계약 enum에 정박하고 4+1 색 클래스로 정규화

날짜: 2026-08-04 · 상태: 확정

## 맥락

styles.css의 브랜드 팔레트 토큰(`--green-*`·`--gold-*`·`--ceramic`·`--neutral-cool`)을
컴포넌트 선택자 약 180곳이 직접 참조하고 있었다 — 브랜드 토큰이 의미 역할을 겸해
테마 교체가 선택자 단위 오버라이드를 요구하는 상태(DESIGN.md §7이 지적한 문제).
2층(의미)이 없어 3층(컴포넌트)이 1층(팔레트)에 직접 결합돼 있었다.

## 결정

**의미 축을 디자이너가 발명하지 않고 계약 enum에서 도출한다**(가이드 §2.2~§2.10).
계약의 모든 상태 enum(근거 수준 2·지역 근거 5·수집 상태 10·예시값 6·최신성 3·변경 6)은
가이드 색 배정표에서 결국 다음 다섯 클래스로 수렴한다:

```
강조(emphasis)  AVAILABLE·EXPLICIT_SPATIAL·FRESH·ADDED 등 — 관측·명시의 긍정 신호
중립(neutral)   미수집·불명·보류·추론 전부 — 품질 문제가 아니다(절대 규칙)
경고(warn)      COLLECTION_FAILED·POSSIBLY_STALE·OFFICIALLY_WITHDRAWN·warnings[]
오류(error)     error.code 9종
근거(evidence)  FILE_OBSERVATION 표기 — 제품 시그니처라 별도 축
```

토큰 3층: 1층 팔레트(테마별 상이) → 2층 의미(같은 변수명, 값만 상이 — 기본값은
그린 팔레트에서 var()로 도출, core는 필요한 토큰만 자체 값) → 3층 컴포넌트(2층만 참조).
액션·표면 계열도 의미 이름으로 통일: `--accent(-strong/-deep/-wash)`·`--band`·
`--surface-1/2/-hover`·`--border-strong`·`--placeholder`·`--focus-ring`.
`--text`·`--muted`·`--bg`·`--card`·`--line` 등 기존 의미형 이름은 2층으로 승격 유지.

## 기각한 대안

- **enum별 개별 토큰(30여 개)**: `--coverage-not-collected-bg` 식. 계약 추가마다 토큰이
  늘고, 색 배정표가 이미 5클래스로 수렴하므로 표현력 이득이 없다. 라벨(문안)은 enum별,
  색은 클래스별 — 축이 다르다.
- **팔레트 기본값 뒤집기(core를 :root로)**: 런북 1층 표기는 웹 기본을 시사하지만,
  이번 STEP의 목표는 의미 층 완성이지 기본 테마 교체가 아니다. 뒤집기는 all/컨시어지
  표면의 시각 변경을 수반해 '시각 불변' 제약과 충돌 — 필요 시 별도 결정으로 미룬다.

## 영향

- 3층에서 팔레트 직접 참조 0건(가드 grep). 시각 불변 — Playwright 22/22 픽셀 일치.
- `data-surface='concierge'` 토글은 기본(그린) 팔레트와 동일 경로라 레이아웃 무결
  (전용 블록 부재 = :root 상속; all 표면 베이스라인 통과가 그 증거).
- 값이 동일한 상태 셀렉터만 status/evidence 토큰으로 재지정했다. **가이드와 어긋난
  기존 색 2건은 보존**(시각 불변 원칙): `MISSING_FROM_SNAPSHOT`이 경고색(가이드는 중립),
  `OFFICIALLY_WITHDRAWN`이 중립(가이드는 경고) — STEP 4(컴포넌트 통합)에서 가이드
  §2.7대로 교정하고 베이스라인을 의도적으로 갱신한다.
  *(이행됨: STEP 4에서 두 셀렉터를 교정하고 베이스라인 갱신 — changes 픽스처가 빈 상태라
  화면에는 아직 드러나지 않으며, CSS 셀렉터 교체로 확인.)*
- 부수 발견: CSS 주석 안의 `INFERRED_*/` 문자열이 주석을 조기 종결시켜 뒤따르는 :root
  블록 전체를 무효화했다 — 시각 베이스라인이 이를 즉시 검출(STEP 1의 존재 이유 실증).
  CSS 주석에 `*/`를 포함하는 enum 나열을 금지한다.
