# 웹 카피 — 페이지별 원문 (2026-08-10, 로컬 실렌더 캡처)

각 페이지에 실제로 표시되는 문장을 읽기 순서대로 옮겼습니다. **고치고 싶은 문장을
이 문서에서 직접 수정**하시거나, 채팅으로 "홈-3을 ~로" 식으로 알려주시면 코드에
반영하고 라벨 가드·vitest·시각 베이스라인을 갱신합니다.

표기 규칙:
- `〔데이터〕` — 서버 값(제목·건수·날짜 등). 카피가 아니므로 수정 대상 아님. 단 그 **주변 틀 문장**은 수정 가능
- ⚠️ — 계약 라벨(labels.js). 표현 수정 가능하나 의미 보존 필수(예: "검토 전"→"미확정" 금지)
- 🔒 — 서버 원문(경고·오류·note). 웹에서 치환 불가 — 고치려면 서버 작업으로 분리
- 표기 없음 — 자유 수정 가능한 UI 카피

여기 없는 문장(빈 결과·오류·로딩·툴팁 등 상태 문구)은 코드 기준
[웹_카피_인벤토리_2026-08.md](웹_카피_인벤토리_2026-08.md)에 있습니다.
