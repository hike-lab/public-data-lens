## 확인된 사항 (Tool-only 클라이언트 대비)

- Prompt·Resource를 지원하지 않는 클라이언트도 `get_context`(호환 Tool)로 서비스 개요·규칙 요약을 얻을 수 있음 — §4.1의 호환 설계 의도대로 동작
- 모든 Tool 응답이 구조화 JSON 텍스트(봉투 포함)로 반환되어 클라이언트 측 파싱 의존성이 없음
- 오류도 동일 구조(`{"error": {...}}`)의 정상 콘텐츠로 반환되어 Tool-call 실패로 처리되지 않음
